v1.1.3 - Background playback protection
- Added battery optimisation exemption (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) with an in-app prompt and a Settings row ("Keep playing in the background")
- Opens the system "Allow" screen so Samsung/Pixel battery managers don't pause music
- Foreground playback service now survives app swipe-away (stopWithTask=false)
- Playback service continues while switching apps, screen off, or minimising

v1.1.2 - Fix hangs/crashes, add play & add-to-playlist buttons
- Fixed "app isn't responding" hang: crash handler now terminates the process cleanly instead of swallowing errors on a dead thread
- Crash reports saved & shown next launch with a Copy-to-clipboard button
- Each song row now has a Play/Pause button and Add (+) button to add the track to a playlist
- Now-playing screen has an "Add to Playlist" button while a track is playing
- Converted service callbacks to multi-listener so screens never unregister/clobber one another (fixed crash after closing now-playing sheet)
- Extra guards: blank/expired song paths skip instead of crashing
- Fixed foreground-service start + audio focus edge cases on Samsung & Pixel devices

v1.1.1 - Stability & crash reporting fixes
- Fixed crash when tapping a song to play (song queue now passed in-process instead of via Intent parcel, avoiding TransactionTooLargeException on large libraries)
- Added global crash reporter: any crash now shows a screen with the error, device info and a "Copy Error" (clipboard) + Share button
- Persisted crash report shown with copy button on next app launch
- Hardened playback: corrupt/missing tracks skip instead of crashing
- Fixed foreground service start on Android 8+/12+ (startForegroundService + placeholder notification) so taps and notification controls never crash
- Safer audio focus & notification control handling on Samsung and Pixel devices
